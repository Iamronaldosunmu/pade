# Pàdé

Marketing site for Pàdé (Yoruba "to meet", pah-DEH): a live video game where people in Lagos meet someone new every five minutes, Fridays 9 to 10pm Lagos time. Profiles stay hidden, and either person can press the buzzer to move on.

Single self-contained `index.html` (no build step). Open it in a browser.

## Brand
- Night ground `#0b0c0f`, gold `#ffc24a` on the à and é
- Archivo (display), Hanken Grotesk (text), DM Mono (time)
- Red `#ff3b2f` is used only for the live buzzer
